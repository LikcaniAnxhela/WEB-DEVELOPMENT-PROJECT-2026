# StudySphere

## Project Description

Study sphere is a student productivity platform developed for the Web Systems Development course at UNYT.

The project aims to help university students organize assignments, manages deadlines and track their study progress.

## Planned Features
-User registration and login
-Task and deadlines management
-Study schedule organization
-Progress dashboard

## Technologies
-HTML
-CSS
-JavaScript
-PHP
-MySQL
